# Sazón & Sugar

Personal recipe box, published as a Claude artifact. Features:

- Recipes with a step-by-step cook mode and built-in timers
- A weekly meal prep planner with a shopping list
- A home pantry inventory
- Recipe import from pasted page text or screenshots

- `app/index.html`: the app (includes the starter recipes and pantry, which it loads on first open).
- `data/`: the recipes converted from *My Cooking Recipes.docx*, plus the pantry inventory.
